# MoodMargins App Privacy worksheet

Updated October 14, 2026 for the Kickstart Exchange integration. The developer confirmed that the previous [App Privacy label](https://appstoreconnect.apple.com/apps/6819079849/distribution/privacy) was published before this SDK was added. **The new Usage Data disclosures below must be added and published before distributing a build containing Exchange.** Apple’s API does not expose or edit these answers. No live privacy label or hosted policy was changed by this integration.

| Questionnaire data type | Current implementation | Purpose if disclosed | Linked to identity | Tracking |
| --- | --- | --- | --- | --- |
| Contact Info → Email Address | No email collected by the app. User-initiated email support is outside the app. | App Functionality | Yes, if support correspondence is retained | No |
| Health & Fitness → Health | Mood selections, sleep, and energy stay on device or in the user's private Apple iCloud store. No developer service receives them. | App Functionality | Private Apple account only | No |
| User Content → Customer Support | No in-app support submission form or upload. | App Functionality | Yes, if voluntarily supplied by email | No |

| Identifiers → User ID / Device ID | No MoodMargins login, advertising ID, or developer account identifier is transmitted. | Not applicable | Not applicable | No |
| Purchases → Purchase History | Verified StoreKit transactions provide access on device; no developer receipt server. Apple processes purchases. | App Functionality | Apple account only | No |
| Usage Data → Product Interaction | Kickstart Exchange records app-level ad impressions, clicks, and reports. | Third-Party Advertising; Developer’s Advertising or Marketing; Analytics; App Functionality | No | No |
| Usage Data → Advertising Data | Kickstart Exchange processes app-level ad delivery and interaction records. | Third-Party Advertising; Developer’s Advertising or Marketing; Analytics; App Functionality | No | No |

The two Usage Data rows are required additions, matching the privacy manifest in KickstartExchange 0.6.0. Keep existing disclosures that still apply; do not remove them solely because this SDK was added. The remaining rows describe the audit rather than recommending collection disclosures: Apple excludes data processed only on device, collected only by Apple, or discarded after real-time processing. [Apple's App Privacy guidance](https://developer.apple.com/app-store/app-privacy-details/), [Exchange disclosure instructions](https://exchange.kickstart.tools/guide#app-privacy).

Audit scope: SwiftData/CloudKit configuration, Foundation Models request snapshots, StoreKit transaction processing, bundled dotLottie animation loading, EZSwiftData, EZCharts, GentleNotification, OnboardingKit, and KickstartExchange 0.6.0. Only the main app links Exchange, with one placement below About in Customize, hidden until entitlements resolve and while Plus is active. Theme ownership and all existing premium access rules are unchanged. Widgets and the Watch app do not link the SDK. No additional package dependency, tracker, advertising identifier, or installation identifier was added. Watch entries remain local. iCloud sync still needs a real two-device test.

Exchange receives app-level configuration, bundle identifier, platform, app/build/SDK versions, and App Store country. For shipping builds it transiently verifies an Apple-signed App Transaction, then discards that signed data without retaining or using user or device values. Individual ad records last approximately 30 days; aggregate app-level statistics may be retained longer. Its network provider processes the connecting IP address to deliver traffic; Exchange does not retain it or use it to identify people. Journal content, moods, tags, AI context, and premium status are not sent to Exchange. [Exchange privacy notice](https://exchange.kickstart.tools/privacy).

Before release, publish the two Usage Data answers as **not linked to identity** and **not used for tracking**, and update the [hosted privacy policy](https://apps.transfinite.us/moodmargins/privacy-policy) using [PrivacyPolicy.txt](PrivacyPolicy.txt), which now includes Exchange and links to its privacy notice. The local age-rating questionnaire now declares advertising; it remains a pending listing edit. The local policy is a draft: verify it reflects actual practices and have a legal professional review it before publishing changes.
