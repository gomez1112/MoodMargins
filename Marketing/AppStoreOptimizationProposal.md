# MoodMargins App Store optimization proposal

Prepared October 11, 2026 using Kickstart. App Store ID: 6819079849.

Status: review draft. This report does not change the tracked listing, Kickstart project records, or App Store Connect.

## Findings

Kickstart reports an overall optimization score of 57/100: title 12, subtitle 99, keywords 58, and description 68. These are heuristic scores, not a forecast of downloads, ranking, or App Review approval.

The current name, “MoodMargins,” preserves the brand but does not explain the app. Adding a functional descriptor makes its purpose immediately visible. The current subtitle is already strong; moving “Mood Journal” into the name allows the subtitle to describe daily diary and emotion tracking.

The existing keyword fields repeat terms already present in the subtitle, especially in Spanish and Arabic. The proposed fields use relevant additional terms instead. The description should open with the app’s purpose, then show the quick check-in, useful Insights, and personal notebook experience. Replace “washi-style tags” with plain “tags”; keep purchase, AI, and sync details accurate.

Kickstart also suggests social proof, custom product pages, events, and A/B tests. No verifiable review or download claims were supplied. Those optional campaigns can be considered after launch; they are not prerequisites for the initial listing.

## Accuracy and publishing notes

The proposal distinguishes free journaling and standard Insights from paid themes, AI suggestions, and recaps. Suggested AI tags require user selection; it does not claim that tags are silently added. Individual themes remain permanent purchases and do not unlock AI. Plus is an auto-renewing subscription.

Private iCloud sync applies to the main app when available and enabled. Watch entries remain in a separate local journal. AI processing starts with Private Cloud Compute, falls back to the local model, and can be set to local processing in Customize. No claims of medical treatment, invented reviews, or guaranteed wellbeing outcomes are added.

No build or code changes are needed for this proposal. Check the tracked listing with Bitrig’s listing validator before publishing an approved batch. App Privacy still needs to be completed in App Store Connect before the release is ready for review.
